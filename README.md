# Sistema de Reserva de Computadoras

## Descripción

Este proyecto es un sistema web para organizar la reserva de computadoras de la biblioteca.

Esta parte corresponde al **Frontend**, donde se realiza el prototipo de la página.

## Funciones

* Inicio de sesión.
* Selección de carrito.
* Selección de horario.
* Selección de computadora.
* Confirmación de la reserva.
* Guardado de datos con `localStorage`.

## Horarios

* 07:40 a 09:40
* 10:00 a 12:00
* 13:10 a 15:10
* 15:30 a 17:30
* 17:40 a 19:40
* 19:50 a 21:50
