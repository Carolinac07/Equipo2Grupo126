# Sistema de Reserva de Computadoras

## Descripción

Este proyecto consiste en el desarrollo de un sistema web para gestionar la reserva de computadoras de la biblioteca escolar.

Actualmente, las reservas se realizan de manera manual. El objetivo del sistema es facilitar y organizar este proceso, permitiendo que los estudiantes puedan consultar las computadoras disponibles y realizar una reserva indicando el día y horario.

## Objetivos

* Organizar las reservas de las computadoras.
* Evitar reservas duplicadas.
* Permitir consultar el estado de las computadoras.
* Facilitar el trabajo del bibliotecario.
* Mantener un registro de las reservas realizadas.

## Funcionamiento

El sistema contará con un inicio de sesión para identificar a los usuarios.

Una vez ingresado, el estudiante podrá:

1. Elegir uno de los dos carros de computadoras.
2. Consultar las computadoras disponibles.
3. Ver el estado de cada computadora.
4. Seleccionar la computadora que desea reservar.
5. Elegir el día y horario de la reserva.
6. Confirmar la reserva.

El bibliotecario podrá consultar las reservas realizadas y gestionar la disponibilidad de las computadoras.

## Horarios de reserva

Las reservas se organizan en los siguientes horarios:

* 07:40 a 09:40
* 10:00 a 12:00
* 13:10 a 15:10
* 15:30 a 17:30
* 17:40 a 19:40
* 19:50 a 21:50

## Recursos

El sistema contempla:

* 2 carros de computadoras.
* 20 computadoras en total.
* Usuarios estudiantes.
* Usuario administrador/bibliotecario.
* Registro de reservas.
